# EAP 回答风格 Demo · 多智能体协作版

“陪伴空间”是临时展示名称。当前版本用于验证 EAP 对话风格、跨场景协作及模拟工具操作。

## 主智能体改造：第一阶段

第一阶段已实现，待用户验收。范围和验收步骤见 [第一阶段验收说明](docs/phase-1-acceptance.md)。

- 能力介绍走通用路径，不调用业务子 Agent、工具或 Composer。
- 单个子 Agent 直接回复，多个子 Agent 才调用 Composer。
- 用户界面、工具结果和新回复按正常 EAP 服务表达；内部保留 `isDemo` 和现有账户存储。
- 匹配前先确认主题、日期、时段和方式；一次给全条件可直接查询。
- 搜索只返回指定日期、时段和方式内的 Slot，卡片与预约确认共用上海时区的时间格式。
- 指定咨询师只展示目标咨询师，预约操作只展示目标结果；当前预约默认排除已取消记录。

动态上下文、Task Ledger、记忆管理、心理支持状态以及人工通道属于后续阶段。

## 运行

双击本目录 `启动网页.cmd`，浏览器打开 http://127.0.0.1:3000 。已有的千问配置继续有效；Key 保存在本机 `.env.local`，不会返回前端或写入导出记录。所有 Agent 共享同一配置，无需分别填写 Key。

## 架构

- 主 Agent：通过独立模型调用理解完整对话，分配一个或多个任务；多意图结果由主 Agent 再合成一条回复。
- 客服 Agent：独立提示词和工具，仅可查询本账户权益、订单及模拟退款。
- 咨询师匹配 Agent：通过对话按“咨询类型 → 期望时间 → 咨询方式”的顺序确认需求，每次最多展示3位咨询师，支持换一批。
- 预约 Agent：负责咨询师卡片上的直接预约，以及已有预约的查询、改约和取消，不再承担咨询师匹配。
- 心理支持 Agent：独立提示词和工具，提供陪聊、检索测试资源、播放音频、逐步进行或停止练习。

子 Agent 使用千问原生 function calling，服务端校验工具权限和参数。独立子任务并行执行，单意图直接采用对应子 Agent 的回复，多意图由主 Agent 整合。每条回复可展开查看协作记录与工具名称，不展示模型内部推理。紧急风险优先由心理支持 Agent 回应，未接入真人或救援。

整轮成功后才保存对话和工具修改；模型失败或停止时未提交的修改丢弃。同一账户的并发请求互斥，业务数据提交有版本检查。

## 测试数据

当前用户为林晓（虚构），初始剩余4次EAP权益。有3笔订单，其中 `ORD-1002` 应付300元、两次各扣300元，重复的一笔尚未申请退款；`ORD-1003` 的180元已模拟退款。

8位虚构咨询师覆盖情绪、家庭、工作、关系和睡眠等方向。时段按上海日期生成未来日期，同时提供线上、线下两种测试咨询方式；账户初始带一条测试预约。资源包含本地可播放的合成声音和两种三步对话式练习，均非经临床审阅的干预材料。

可直接提问：

- “帮我查一下为什么扣了两次钱，我的EAP还剩几次？”
- “我想找一位合适的咨询师。”
- “我想听一小段放松音频。”
- “带我做一个把注意力带回此刻的练习。”
- “我最近压力很大，也查下我的权益，再找位300元以内的咨询师。”

需求确认完整后会展示咨询师卡片，每批最多3位，可换一批。用户在卡片上选择咨询方式和具体时间后直接预约，成功时自动追加预约完成消息；后台仍会再次检查时段和EAP权益。预约和退款没有真实费用，也不会联系真人。

## 数据与开发

对话会发送至配置的千问服务，本地页面不意味着数据不出本机。聊天记录、逐条反馈、工具卡片、协作记录、练习进度及测试账户业务数据一起保存在 `.demo-data/`，关闭网页、闲置或重启服务后仍保留。成功回复和业务操作通过同一份账户文件原子保存；失败或中断的本轮不保存。旧版进程中仍存在的记录可在升级前迁移，已经丢失的内存记录无法自动恢复。

同一浏览器保留 `eap_workspace` 身份cookie（有效期1年，每次访问续期），重新打开时默认恢复上次选择的对话；侧栏可展开全部历史。请继续使用同一个地址与浏览器。当前没有跨设备登录：清除cookie、换浏览器或切换 `localhost`/`127.0.0.1` 会被识别为另一个账户，但不会删除原有本地数据。`.demo-data/` 里的记录是本机文件，尚无账户登录、存储加密或真实企业权限集成。

需要 Node.js 20.9 以上及 pnpm；测试命令使用 Node.js 24 的 TypeScript 支持。

```text
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm test:integration
```

集成测试启动独立的本机模拟模型和应用进程，使用临时数据目录，不读取或修改已有 Key。官方千问接口参考：https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope
